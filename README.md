# UMAI CLINIC

Готовый современный статический сайт медицинского центра UMAI CLINIC в Алматы (ТОО «PregnaMed»). Откройте `index.html` в любом браузере или через Live Server в редакторе. Сборка, установка пакетов и серверная часть не требуются.

## Содержимое проекта

- `team.html` — отдельная страница «Наша команда», доступная из меню и подвала главной страницы. Использует фирменную палитру из гайдлайна, оригинальный логотип, орнаменты и локальный Geologica; поддерживает RU / KK / EN, мобильную версию и обе темы.
- `team.css`, `team-content.js`, `team.js` — оформление, анкеты на трёх языках, поиск по имени / специальности и фильтр врачей. На странице шесть демонстрационных анкет: портрет, ФИО, специальность, стаж, категория, языки приёма, образование, опыт и повышение квалификации. Данные вымышленные, портреты сгенерированы ИИ; это явно указано на странице. Кнопки в карточках ведут в форму с выбранным направлением врача через `index.html?service=N#appointment`. Поле `serviceIndex` каждой анкеты — индекс направления в `CLINIC_CONTENT.ru.services`, начиная с нуля (например, `0` — гинекология, `12` — кардиология). При смене специальности обновите и этот индекс. Общие кнопки записи не задают направление.
- `assets/img/team/doctor-1.png` … `doctor-6.png` — локальные демонстрационные портреты. Использован встроенный `image_gen`; полные промпты сохранены в `assets/img/team/PROMPTS.md`.
- Чтобы заменить шаблон реальными данными, обновите фотографии и массив `CLINIC_DOCTORS` в `team-content.js` (поля `ru`, `kk`, `en`), затем выполните `node clinic-site/scripts/build-team.cjs` из корня проекта или `node scripts/build-team.cjs` из папки `clinic-site`. Скрипт обновляет статические анкеты в `team.html`, доступные также без JavaScript. Для обычного просмотра Node.js не требуется. После замены всех демонстрационных данных уберите пометки об образцах в HTML и генераторе.
- **Блок «Цены»** (`index.html`, раздел `#prices`) — 47 основных позиций из прайс-листа клиники от 12.10.2026, сгруппированных в 6 карточек: консультации, УЗИ и функциональная диагностика, анализы, процедуры, массаж, программы наблюдения. Полный прайс (около 430 позиций) на сайт не выводится: его выдаёт администратор. Чтобы поменять цену, исправьте число в теге `<b class="price-num">`: оно общее для всех языков. Слово «от» показывается только у позиций с переменной ценой (у них перед ценой есть `<span data-i18n="pricePrefix">`). Названия услуг на трёх языках лежат в `content.js` (ключи `pl_*`, заголовки карточек — `plGroup*`). Чтобы добавить строку, скопируйте `<div>` внутри `<dl class="price-list">` и заведите новый ключ `pl_…` для `ru`, `kk` и `en`. При обновлении прайса поменяйте дату в тексте `pricesLead` в `content.js` (на трёх языках) и в `index.html`.
- `privacy.html`, `privacy-content.js` — страница «Политика конфиденциальности» на RU / KK / EN. Ссылки на неё есть в подвале и в форме записи. Отправить форму нельзя, пока не отмечена галочка согласия на обработку персональных данных. Текст политики хранится в `CLINIC_PRIVACY` в `privacy-content.js`. После правки выполните `node scripts/build-privacy.cjs`: скрипт обновит статическую русскую версию в `privacy.html`, которая доступна и без JavaScript. При изменении текста обновите дату редакции (`privacyUpdated`).
- `index.html` — основная страница с полной семантической разметкой, доступной без JavaScript и оптимизированной для поисковых систем (SEO, OpenGraph, JSON-LD schema.org). В JSON-LD описаны клиника (`MedicalClinic`: адрес, часы работы, специальности, список услуг, карта) и раздел вопросов (`FAQPage`). Цены в разметку не добавлены, пока в блоке «Цены» стоят образцы. Когда появятся реальные цены, их можно добавить в `availableService` через `offers`.
- `styles.css` — адаптивное оформление с поддержкой светлой и тёмной тем, микроанимациями, стилями для мобильных устройств и планшетов.
- `fonts.css`, `assets/fonts/` — локальные шрифты Comfortaa и Manrope в формате WOFF2 (без внешних запросов к Google Fonts, полная автономность).
- `app.js` — интерактивная логика: переключение языков, поиск и фильтрация услуг, модальные окна с описанием направлений, маска номера телефона, генератор сообщений WhatsApp, переключатель тем, плавающий виджет связи.
- `content.js` — тексты на русском, казахском и английском языках, подробные описания всех 14 направлений, памятка пациенту, ответы на частые вопросы (FAQ).
- `assets/img/`, `favicon.svg` — фотографии фасада, холла клиники, изображение для соцсетей и значок сайта.
- `.htaccess`, `robots.txt`, `sitemap.xml` — конфигурация для размещения на сервере Apache/Nginx.

## Реализованные возможности

1. **Мультиязычность (RU / KK / EN)**:
   - Полная поддержка трёх языков с мгновенным переключением без перезагрузки страницы.
   - Сохранение выбранного языка в `localStorage` (`umai-lang`).
   - Синхронное обновление заголовков, мета-тегов, описаний услуг, модальных окон и подсказок.

2. **Каталог направлений с деталями**:
   - 14 медицинских направлений: акушерство и гинекология, терапия, педиатрия, урология, хирургия, УЗИ, лабораторные анализы, процедурный кабинет, маммология, эндокринология, гастроэнтерология, неврология, кардиология, массаж.
   - Быстрый живой поиск по названию, врачу или симптомам.
   - Фильтрация по категориям: Все, Консультации, Диагностика, Процедуры.
   - Интерактивное модальное окно «Подробнее» с полным перечнем того, что входит в приём, показаниями и подготовкой.

3. **Интерактивная запись на приём**:
   - Выбор направления из выпадающего списка (с автовыбором при клике на услугу).
   - Поля для ввода имени, телефона (с автоматической маской `+7 (___) ___-__-__`), желаемой даты и времени визита, а также комментариев/симптомов.
   - Календарь не даёт выбрать прошедшую дату (по времени Алматы), воскресенье и субботний вечер после 15:00. Сообщения об этом выводятся на выбранном языке. Проверка находится в `validateVisitDate()` в `app.js`; при изменении графика работы обновите её вместе с подсказкой `dateHint` в `content.js`.
   - Автоматическое формирование вежливого, структурированного сообщения для WhatsApp на выбранном языке.
   - Альтернативная кнопка прямого звонка администратору: +7 (775) 007-66-81.

4. **Памятка пациенту перед визитом**:
   - Правила подготовки к ультразвуковым исследованиям (УЗИ брюшной полости, малого таза, щитовидной железы).
   - Рекомендации по сдаче лабораторных анализов (натощак, диета накануне, питьевой режим).
   - Список документов и выписок, которые стоит взять с собой.

5. **Вопросы и ответы (FAQ)**:
   - Интерактивный аккордеон с частыми вопросами пациентов (запись, подготовка, оплата и приём).
   - Полная поддержка мультиязычности и доступность для клавиатурной навигации.

6. **Контакты и схема проезда**:
   - Адрес: г. Алматы, ул. Кажымукана, 101/1, корпус 15 (ЖК Elite Life).
   - Кнопка построения маршрута в 2ГИС.
   - Карта 2ГИС (виджет организации, ID `70000001118453662`): показывает карточку клиники с адресом, телефоном, часами работы и кнопкой маршрута. ## Размещение на хостинге

Загрузите содержимое папки `clinic-site` в корень вашего сайта `umai-clinic.kz` (или в `public_html`), сохранив структуру папки `assets`.
Файл `.htaccess` настроен на принудительный HTTPS, работу без www, кеширование статики и gzip/brotli сжатие.

### Страница 404, иконки и защитные заголовки

- `404.html` и `notfound-content.js` — фирменная страница «Такой страницы нет» на трёх языках, с кнопками «На главную» и «Записаться» и ссылками на основные разделы. Она подключена в `.htaccess` (`ErrorDocument 404 /404.html`) и закрыта от индексации (`noindex`). Все пути внутри неё начинаются с `/`, чтобы она правильно выглядела на любом неверном адресе, даже вложенном (`/a/b/c`). Поэтому открывать её нужно через сервер, а не двойным щелчком по файлу.
- `favicon.ico`, `manifest.webmanifest`, `assets/img/icons/` — иконки сайта. `favicon.ico` показывает Яндекс в выдаче и старые браузеры. `apple-touch-icon.png` и иконки 192/512 используются, когда сайт добавляют на главный экран iPhone или Android. Иконки построены из знака `assets/img/logo-mark.svg` на фоне «тёплое молоко».
- Защитные заголовки в `.htaccess`:
  - HSTS — браузер открывает сайт только по HTTPS;
  - `Permissions-Policy` — у сайта нет доступа к камере, микрофону, геолокации, оплате и USB;
  - `X-Frame-Options` — сайт нельзя встроить во фрейм на чужом домене;
  - `Content-Security-Policy` — разрешены только собственные скрипты сайта и iframe виджета 2ГИС для карты.
- **Важно про CSP.** При подключении аналитики (Яндекс Метрика, Google Analytics), чат-виджета или других внешних скриптов добавьте их домены в `script-src`, `connect-src`, `img-src` (и `frame-src` для виджетов) в `.htaccess`. Иначе браузер их заблокирует. Если меняете встроенный скрипт `document.documentElement.classList.add('js');` в `<head>`, пересчитайте его sha256-хеш в `script-src`.
- Файлы `README.md` и `scripts/*.cjs` закрыты от доступа из браузера.

### Если хостинг работает на Nginx

Nginx не читает `.htaccess`. Те же настройки нужно добавить в блок `server`:

```nginx
error_page 404 /404.html;
location ~ (README\.md|\.cjs)$ { deny all; }
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Strict-Transport-Security "max-age=31536000" always;
add_header Permissions-Policy "camera=(), microphone=(), geolocation=(), payment=(), usb=()" always;
add_header X-Frame-Options "SAMEORIGIN" always;
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'sha256-/x7W7R75k8Roq0WaVRQX9blP4OufE5xbAdzklGxsgpw='; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; frame-src https://widgets.2gis.com; manifest-src 'self'; base-uri 'self'; form-action 'self' https://wa.me https://api.whatsapp.com https://web.whatsapp.com; frame-ancestors 'self'; object-src 'none'; upgrade-insecure-requests" always;
types { application/manifest+json webmanifest; }
```
